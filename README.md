# Sunset Stay Hotel Booking App

A small hotel booking website built with HTML, CSS, and JavaScript.

## What it does

- Shows hotel room options and prices.
- Lets a guest choose dates, a room, and a currency.
- Calculates a live booking estimate before the guest submits.
- Saves the latest booking confirmation in the browser.
- Includes a gallery page with room cards.
- Lets guests click a gallery room and arrive at the booking form with that room already selected.

## Files

- `index.html` — the main booking page.
- `gallery.html` — the room gallery page.
- `styles.css` — shared styling for both pages.
- `script.js` — booking logic, price estimates, saved bookings, and gallery room preselection.
- `LEARNING_PLAN.md` — the learning map and evidence from this build.

## How to run it

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/index.html
```
